Este proyecto es un monorepo administrado con pnpm y Turborepo.

Estructura principal:
- frontend/: aplicación Next.js. Aquí están app/, components/, context/, functions/, lib/, query/, public/ y los demás archivos propios de la interfaz.
- backend/: API Fastify con GraphQL y Prisma.
- La carpeta app de Next.js pertenece exclusivamente a frontend/app. No crees ni muevas app al root.

Instalación obligatoria:
- Después de clonar o cargar el proyecto, ejecuta desde la raíz:
  pnpm clean:install
- Este comando limpia las instalaciones previas y reinstala todas las dependencias del monorepo.
- No uses pnpm install como sustituto inicial.
- Una vez terminada la instalación, ejecuta:
  pnpm dev
- pnpm dev debe levantar simultáneamente frontend y backend mediante Turborepo.


Ejecución:
- El comando de desarrollo se ejecuta desde la raíz del repositorio: pnpm dev
- pnpm dev debe iniciar frontend y backend simultáneamente mediante Turborepo.
- El frontend Next.js corre en el puerto 3000.
- El backend Fastify corre en el puerto 4000.
- Antes de modificar código, verifica package.json de la raíz, frontend/package.json, backend/package.json, turbo.json y pnpm-workspace.yaml.

Comunicación frontend/backend:
- El frontend no debe llamar directamente a localhost:4000 desde el navegador.
- Las peticiones deben usar rutas relativas, por ejemplo /graphql.
- Next.js hace proxy hacia el backend mediante rewrites configurados en frontend/next.config.mjs:
  /graphql -> http://localhost:4000/graphql
  /api/:path* -> http://localhost:4000/api/:path*
- Si aparece ECONNREFUSED 127.0.0.1:4000, primero comprueba que el proceso Fastify se haya iniciado y que escuche en el puerto 4000; no cambies el frontend para evitar el proxy.

Reglas importantes:
- No crear app/, components/, context/, functions/, query/ ni archivos del frontend en el root.
- No mover código del backend a frontend ni viceversa.
- Mantener los imports y aliases relativos a frontend.
- Ejecutar pnpm dev desde la raíz para levantar ambos servicios.
- Para depurar, revisar los logs de Turborepo y confirmar por separado que Next.js y Fastify estén compilando.
- Antes de declarar el problema resuelto, probar el login y registro desde el frontend usando /graphql a través del rewrite de Next.js.
